# T010 pool thermostat

Verified on firmware **1.7** through a Modbus TCP-to-RS-485 gateway. The
register map below was taken from the device firmware; the firmware itself is
not part of this repository.

## Communication

- Modbus RTU, 38400 8N1, fixed in the firmware.
- Modbus ID 1–32, factory default 1, set in the device menu.
- Function 03 reads addresses 0–9, at most 10 registers per request.
- Function 06 writes addresses 5–9. No other function codes.
- Exceptions: 1 unsupported function, 2 bad address or register count, 3 value
  out of range.
- Standard addressing: register *n* is address *n*.

## Register map

| Address | Read/write | Content |
|---|---|---|
| 0 | R | High byte: instrument type, `0x15` for a T010. Low byte: software version × 10 (17 = 1.7) |
| 1 | R | Water temperature × 10 (°C), offset already applied |
| 2 | R | Heating power, % (low byte) |
| 3 | R | Heating delay still to run: minutes (high byte), seconds (low byte) |
| 4 | R | Always 0 |
| 5 | R/W | Setpoint × 10 (°C). Accepts 50–400; anything else returns exception 3 |
| 6 | R/W | Temperature offset × 10 (°C), signed (high byte 0xFF when negative). Clamped to ±31 |
| 7 | R/W | Heating delay setting, minutes. Accepts 0–59; more returns exception 3 |
| 8 | R/W | Flags, below |
| 9 | R/W | Reserve; kept in RAM only, lost on power cycle |

Register 8:

| Bit | Read/write | Meaning |
|---|---|---|
| 0 | R | Menu open on the device |
| 1 | R | Sensor disconnected: raw temperature below 3.1 °C |
| 2 | R | Sensor supply below 6.0 V for about 2 s (masks bit 1) |
| 3 | R | EEPROM read/write error |
| 8 | R/W | Heating blocked |
| 9 | R/W | Delaying |

A write to register 8 only changes bits 8 and 9. The firmware does not check
whether the device menu is open, so Modbus writes take effect then too.

## Behaviour

- **Heating power.** In relay mode the output is 0 or 100 %. In PWM mode it is
  100 % when the setpoint is 0.5 °C or more above the water temperature, and
  20, 40, 60 or 80 % for a gap of 0.1–0.4 °C.
- **Relay control.** On when the temperature is 0.2 °C below the setpoint, off
  5 s after reaching it.
- **Heating is off** while it is blocked, while the delay runs, and while any
  alarm bit is set.
- **The delay also runs at every power-up.**
- **Near-freezing water reads as a sensor fault**, since anything below 3.1 °C
  sets bit 1.
- **Writes are stored in EEPROM**: setpoint, offset, delay and register 8. Avoid
  writing them every few minutes.

## Values shown by this library

Pool Thermostat (heat/off) and Thermostat Action (heating/idle/off) follow Home
Assistant's thermostat logic: the thermostat is in heat mode unless heating is
blocked, and heating whenever the heating power is above 0 %.
